DSH rclone Drive Integration

Personal Google Drive integration using rclone and OAuth 2.0.

About

This is a personal, non-commercial integration that allows the owner to access and manage their own Google Drive files using rclone and a local AI-assisted workflow.

How it works

  • Google OAuth 2.0 authorizes access.
  • rclone handles Google Drive API requests.
  • Access requires authorization by the Google account owner.
  • The application is not offered as a public service.
